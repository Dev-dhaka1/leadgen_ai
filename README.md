# 🚀 LeadGen AI

A CrewAI-powered Lead Generation and Cold Outreach system that autonomously finds prospects, researches companies, and writes personalized cold emails.

---

## 🧠 How It Works

1. **Lead Research** — Searches the web for business leads matching your query
2. **Company Research** — Visits each company website and extracts key info
3. **Personalization** — Identifies pain points and crafts outreach angles
4. **Outreach** — Writes personalized cold emails and saves them to `data/`
